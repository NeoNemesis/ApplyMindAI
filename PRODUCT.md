# Product

## Register

product

## Users

Job seekers (primarily Swedish market) who apply to many positions at once. Technical and non-technical users who want automation. Used at a desk, often multiple times per week, in a focused task-completion mindset. Primary workflow: configure search criteria, trigger job scraping, review and download generated CVs and cover letters.

## Product Purpose

ApplyMind AI automates the job application process: scrapes job boards (Indeed, Arbetsförmedlingen, Jobtech), scores matches via AI, generates tailored CVs and cover letters, and tracks application status. Success means a user can go from "I need jobs" to "I have 10 tailored applications ready" in minutes with minimal manual effort.

## Brand Personality

Precise, dependable, efficient. The tool does serious work — it shouldn't feel playful or generic. Feels like a professional instrument, not a startup MVP.

## Anti-references

- Generic SaaS landing page aesthetics (purple gradients, hero metrics with big numbers)
- Cluttered admin panels (Bootstrap default theming, navy sidebars)
- "AI startup" visual language (neon mesh backgrounds, glowing orbs)
- Overly decorated dashboards that compete with the data

## Design Principles

1. **Data first** — UI chrome should recede; the job data and application status are the product
2. **No decoration tax** — every visual element earns its place by aiding comprehension or navigation
3. **Consistent rhythm** — spacing, sizing, and color follow a defined system, never eyeballed
4. **Accessible by default** — focus states, contrast, and keyboard nav are non-negotiable
5. **Tool confidence** — the interface should feel like a well-engineered instrument, not a polished marketing site

## Accessibility & Inclusion

WCAG AA minimum. Keyboard navigable. Focus rings visible. Contrast ratios met for all text. Reduced motion respected.
